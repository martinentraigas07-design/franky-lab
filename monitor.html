MONITOR
Que es esto

Herramienta VISUAL para observar el sistema en vivo: eventos, estados y salidas generadas por Blockly/Sumo — en tiempo real. Es la version de pantalla completa del mismo Monitor que aparece como boton flotante en el resto de las paginas del LAB (util en pantallas chicas, donde el flotante puede quedar incomodo).

Esto NO es la bitacora tecnica del sistema — para eso existe /log, un registro completo en texto plano pensado para copiar y compartir, no para leerse comodo en pantalla. Este Monitor es una simulacion de navegador (FRANKY LAB) — NO es el puerto serie de un ESP32 fisico.

Registro en vivo

Se actualiza cada 1,5s. Los botones (Pausar / Debug / Guardar / Limpiar) son los mismos del Monitor flotante que ya existe en el resto de las paginas — es el mismo sistema, mostrado completo en esta pagina en vez de en la ventana chica.
