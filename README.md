# franky-lab
FRANKY LAB  Laboratorio Virtual Oficial del proyecto FRANKY.  Permite simular el funcionamiento del robot FRANKY utilizando el mismo Servidor Web y el mismo Runtime que el firmware físico.  Incluye:  • Workspace • Blockly • Gamepad • Minisumo • Fútbol • Laberinto • Seguidor de Línea • Física • Simulación de sensores • Hardware Workspace
